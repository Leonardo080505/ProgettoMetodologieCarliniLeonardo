# Hacker Network
Gioco di ruolo dove giocatore impersona un hacker che deve esplorare una rete di nodi, violare server dati per incrementare la propria abilità, evitare trappole ed infiltrarsi fino a violare il **Mainframe Riservato**


-----------------------------------------------
## 🚀 Come eseguire il progetto
 **Prerequisiti**
* **Java25**
* **Gradle**

**Istruzioni**
```bash
git clone https://github.com/Leonardo080505/ProgettoMetodologieCarliniLeonardo.git
cd ProgettoMetodologieCarliniLeonardo
```

### Build del progetto

```bash
./gradlew build
```

### Esecuzione

```bash
./gradlew run
```

## 🤖 Uso di strumenti di AI

Utilizzato Gemini (Google) come supporto durante lo sviluppo per:


* Chiarire errori di compilazione e problemi di configurazione
* Ricevere suggerimenti sull'architettura a layer 
* Generare bozze di classi poi riviste,comprese e successivamente adattate 

Comunque:
* tutto il codice è stato comopreso ed analizzato prima di essere integrata nella repository
* tutte le scelte architetturali sono state decise personalmente prendendo i suggerimenti chiesti all'IA solo come tali
* l'AI è stata usata come supporto tecnico, non come sostituto del ragionamento
